## 说明与未验证项

- **MySQL**：`mysql_tables` 用 `SHOW TABLE STATUS`，`mysql_describe` 用 `SHOW FULL COLUMNS` + `SHOW INDEX`；不使用 `information_schema`。`mysql_query` 的 LIMIT 由 sqlglot 重写，`SHOW` 不补。
- **Mongo**：聚合尾自动追加 `$limit`，`find`/`aggregate` 带 `maxTimeMS`；`mongo_collections` 用 `listCollections` + `collStats`。
- **ES**：`size > max_rows` 直接拒绝，`from + size` 仍受 10000 限制；mapping 只读 `_mapping` 与 `_settings`。
- **Redis**：`redis_get` 对 list/set/zset 先探测长度，超过 `max_rows` 拒绝；`key_prefix` 同时约束 scan pattern。
- **未验证**：真实 MySQL / Mongo / Elasticsearch / Redis 的连通性与返回结构；本机未安装 `asyncmy` / `motor` / `redis` 驱动，真实查询需对应 extras 与只读凭证后手测。
