## 弹窗关闭按钮修复

结果弹窗的 `×` 之前绑定了 `data-dialog-close`，处理器无条件 `preventDefault()`，只关闭弹窗不导航；弹窗已关闭后再次点击也会被拦截，表现为按钮无效。

已改为：

- `data-dialog-close="navigate"` 的链接先关闭弹窗，再 `window.location.assign(href)`；
- 弹窗已经关闭时不再拦截链接默认跳转；
- 无 JS 时链接直接跳转。

真实 Chrome 验证：点击 `×` 后 URL 回到 `/me`。

Token 结果弹窗中的“返回 Token 列表”按钮已按用户要求移除，避免与右上角关闭重复。
