# Web 多语言（en / zh-Hans）

## 结论

Web 配置台现在支持：

- 默认语言：**English**
- 支持语言：`en`、`zh-Hans`
- 语言切换：顶部 `EN / 中文`，POST `/language` + Cookie
- 服务端渲染、零 JS；不改变现有 URL

## 语言解析

- Cookie：`drpanda_lang`
- 合法值：`en`、`zh-Hans`；未知值回退 `en`
- 无 Cookie：`en`，不读取 `Accept-Language`
- `html lang`、`Content-Language` 与 Cookie 一致
- 语言切换保留当前路径和查询串（包括设置页 `?section=`）

实现：[web/i18n.py](../../src/dr_panda_mcp/web/i18n.py)、[web/render.py](../../src/dr_panda_mcp/web/render.py)、[web/routes.py](../../src/dr_panda_mcp/web/routes.py)。

## 文案机制

- 模板使用全局 `t("中文源文案")`。
- `web/locales/en.json` 是中文源文案 → 英文的 catalog；`zh-Hans` 直接返回中文源文案。
- 缺失翻译回退源文案；翻译时做了 HTML 自动转义。
- 主要页面已英文覆盖：
  - 顶栏/导航/主题/语言切换
  - 目标列表、空状态、筛选、表格
  - 新建类型页、表单、字段 label/help、密钥提示
  - 设置页全部分组、字段、效果、启动配置、历史
  - 删除页、恢复默认页、错误页
- 设置页目标 scope 已改为 `scope_source + params`，由 `t` 渲染。

## 测试

新增：

- 默认无 Cookie 时为英文；
- `POST /language` 写 Cookie，切到中文并保留设置页 section；
- 非法语言回退英文；
- 英文页面扫描：主要页面不出现中文硬编码（语言选择器里的“简体中文”除外）。

全量：**442 passed**，`ruff` 通过。
