## 说明与未验证项

- **RabbitMQ**：`rabbit_queues` 不传 vhost 时只遍历授权 vhost；`rabbit_queue` 单队列详情；不使用 AMQP 的 `basic.get` / `basic.consume`。
- **Kafka**：`kafka_lag` 用 Admin 读已提交位点 + 无组消费者读 high；`kafka_offsets` 读 low/high；`kafka_peek` 先硬校验 low watermark，再 `assign + seek`；不加入消费组、不提交 offset、不建生产者。
- **未验证**：真实 RabbitMQ（缺凭证）与 Kafka（缺 `aiokafka`、缺 broker/凭证）的连通性与返回结构；`aiokafka` 管理 API 的版本差异需真实实例抽查。
