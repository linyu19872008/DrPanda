# 系统配置页真实浏览器验收

## 环境

- Chrome 156.0.8078.74，`--headless=old`
- 应用：`http://127.0.0.1:8111/settings`
- 通过 Chrome DevTools Protocol 设置真实 viewport 并截图，不使用静态 HTML 合成图。

## 截图

- [1440px](assets/ui/settings-1440.png)
- [390px](assets/ui/settings-390.png)

## 布局检查

| viewport | `innerWidth` | `scrollWidth` | 结果 |
|---|---:|---:|---|
| 1440 | 1440 | 1440 | 无横向滚动 |
| 390 | 390 | 390 | 无横向滚动 |

390px 下分组、字段、右侧只读卡片按单列排列；保存/恢复按钮拉通。

## 键盘走查

从 `body` 开始连续按 Tab，焦点顺序：

1. 跳到主要内容
2. 品牌链接
3. 排查目标
4. 系统配置
5. 主题三态按钮（跟随系统 / 浅色 / 深色）
6. 每项字段的“恢复默认”链接 + 数字输入，按分组顺序：
   - 新建目标默认值（3 项）
   - 并发与审计（3 项）
   - 高级资源（1 项）
7. 恢复全部默认值
8. 保存配置
9. 回到页首跳过链接

所有可交互控件都可达，无键盘陷阱；每项 reset 链接的 `href` 指向 `/settings/reset?key=<key>`。

## 结论

- 分组和移动端布局真实 Chrome 下通过。
- 无横向滚动；焦点顺序与 DOM/视觉顺序一致。
- 单项恢复默认与全局恢复默认都有可聚焦入口。
