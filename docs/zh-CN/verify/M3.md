## 说明与未验证项

- **三客户端未验证**：本记录只证明 `/mcp` 的 HTTP 协议通路与工具调用可用；Cursor / Codex / DeepSeek Harness 的实际界面与配置需在有客户端的环境手测，不当作通过。
- **真实上游连通性未验证**：网页"测试连接"在缺少客户端库时返回明确错误（例如 `mysql 客户端未安装：uv sync --extra mysql`），验证的是错误落库与展示路径；真实连通性仍属 M4/M5 手测项。
- **审计清理任务**：`main()` 启动后由后台协程执行（60 秒首跑、每小时一轮）；测试直接调用 `audit.cleanup_once` 与 `store.cleanup_audit` 验证行为，后台循环本身不在测试里等待。
