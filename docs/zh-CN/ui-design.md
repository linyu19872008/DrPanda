# 配置台视觉与交互设计

本文件是配置台网页的设计系统与页面规格，配合 `src/dr_panda_mcp/web/static/app.css` 使用。技术约束见 [planning.md](planning.md) 4.4：服务端渲染、手写 CSS、无外部字体/CDN；采用服务端优先 + 局部 JS 渐进增强。

## 1. 设计原则

1. **状态优先**：启用/停用、测试成功/失败、密钥可用/不可用，半秒内可辨；信息用「色点 + 徽标 + 文字」三重表达，不依赖颜色。
2. **操作有层级**：每页只有一个主操作（新建/保存/确认删除）；测试与编辑为次级；删除为危险次级。
3. **反馈闭环**：提交后必有结果提示；错误可定位到字段；危险操作先确认。
4. **克制**：中性低饱和 + 单一蓝色强调；系统字体；无外部请求；动效只用于 hover/focus 与状态过渡。
5. **可访问**：键盘可达、焦点可见、对比度达标、错误可被读屏感知；窄屏可用。

## 3.5 首次安装与登录

- `/setup`：两步卡片式向导，第 1 步管理员密码，第 2 步配置库选择/连接测试；不显示主导航，保留品牌与语言切换。
- 数据库类型用链接切换 SQLite / MySQL / PostgreSQL，零 JS；测试成功后才启用“完成安装”。
- 安装完成页显示 MCP URL 与 Token；完整 Token 不在后续页面回显。Token 结果弹窗提供复制按钮（自托管 `copy-token.js`，JS 失败时隐藏按钮并显示手动复制提示）。
- “我的”页上方三个子标签：MCP 访问（默认）、账号、修改密码。改密码失败时留在修改密码。Token 用原生 `<dialog>` + 自托管 `app.js` 创建/删除，JS 可用时不跳页；无 JS 回退到独立表单/确认页；创建成功弹窗显示一次 Token。
- `/login`：单列登录卡片，用户名/密码 + CSRF；不显示管理导航的可操作入口。
- 安装/登录页均已接入 `t()` 中英文文案。

## 4. 语言与主题机制

- 语言：默认英文，Cookie `drpanda_lang` 持久化；`en` / `zh-Hans`；顶部 POST `/language` 切换，保留当前路径与设置页 section；零 JS。
- 主题：

```
无 Cookie                 → <html> 无 data-theme；CSS prefers-color-scheme 跟随系统
Cookie=light / dark       → <html data-theme="light|dark">；服务端渲染，无闪烁
POST /theme mode=system   → 清除 Cookie，回到跟随系统
```

- Cookie 名 `drpanda_theme`，`Path=/; Max-Age=1y; HttpOnly; SameSite=Lax`；`next` 只接受站内路径（拒绝 `//`、协议、主机）。
- 切换是普通表单 POST + 303 回原页；不需要 JS，也不会有首屏闪烁。
- 原生控件颜色由 `color-scheme` 跟随主题。

## 5. 页面规格

### 5.1 概览 `/`

登录后的默认页，品牌也回到这里。所有角色看到同一套个人概览：

- 三个数字：可查询的目标数（只计已启用环境里的已启用目标）、自己的 Token 数、近 24 小时自己的工具调用数；没有 Token 时给出「去生成 Token」。
- 最多 5 条自己的工具调用，显示时间、环境（展示名 + 调用标识）、目标名、工具名与结果，不展示 SQL。
- 管理员额外看到页头入口：「管理概览」按钮 +「N 个目标需要处理」计数徽标（没有异常时显示「没有需要处理的目标」）。

#### 管理概览 `/admin/overview`

仅管理员可见（服务端 403）。四个全局数字（环境、已启用目标、最近测试失败、密钥异常），最多 5 个需要处理的目标（名称链到该目标的编辑页），以及全体用户最近 5 条操作（显示时间、操作者、动作、环境、对象与摘要，含详情弹层与「查看全部」）。失败数大于 0 用危险色，密钥异常用警告色。不展示主机、账号和密钥。

### 5.2 目标列表 `/targets`

- 页面头：h1「目标」+「管理环境」+ 主按钮「新建目标」。主按钮打开右侧抽屉，列出八个类型和当前环境；点类型进入表单，并带上当前环境。没有脚本时按钮仍打开 `/targets/new`。
- 环境切换在统计之前：每张卡片是展示名、调用标识和目标数。当前环境用强调色左边线。最后一张虚线卡片打开新建环境抽屉。
- 当前环境停用时，说明排查时不能查询，配置仍保留。
- 空状态：当前环境没有目标时给出类型名入口，直接进入对应表单，说明选类型并填写连接和允许访问的范围。别的环境已有目标时，标题是「这个环境还没有目标」。还没有环境时，说明先新建环境再登记目标，按钮打开新建环境抽屉。
- 统计：目标总数 / 已启用 / 最近测试失败 / 密钥异常（异常项标红/标黄）。
- 密钥异常时显示全局警告条。
- 工具栏：搜索（`q`，GET）+ 类型筛选（带计数）+ 清除筛选。
- 单表列：名称（链接，密钥异常加徽标）｜类型徽标｜端点（等宽，截断 + title）｜授权范围摘要｜状态开关｜最近测试（状态点 + 浏览器本地时间，悬停仍是 UTC + 失败详情折叠）｜操作（测试/编辑/删除）。
- 失败详情在「客户端未安装」时只提供「安装」。确认后由服务在当前项目执行 `uv sync --extra <name> --inexact`，不会卸掉其他已装客户端，装完立刻再测。页面不展示、也不复制这条命令。
- 空状态：无目标时显示八个类型名；搜索无结果时显示「没有匹配的目标」+ 清除筛选。

**分析员只读版本**：同一个 `/targets` 按角色渲染。没有「管理环境」「新建目标」，环境切换里没有「新建环境」；统计四张卡都保留；表格去掉操作列，名称不再链接编辑页；保留端点、授权范围（按类型列出具体的库/索引/vhost/topic 或 key 前缀）、状态和最近测试（含失败详情，不给安装按钮）。页头副标题说明只读。服务端只放行 `GET /targets`，新建、编辑、删除、启停、测试、安装仍只有管理员。

### 5.3 类型选择 `/targets/new`

八张卡片只显示类型名，点击进入对应表单；页面头提供返回列表。当前环境写在卡片上方：展示名、调用标识，以及保存后不能换环境。列表页的主按钮用抽屉完成同一次选择；这个页面留给直接打开和没有脚本的时候。

### 5.4 新建 / 编辑表单

- 面包屑：目标 / 类型（编辑时附名称）。
- 两栏：主表单 + 帮助侧栏。
- 分区：基本信息 → 连接 → 授权范围 → 高级设置（TLS、证书、运行限制，默认折叠）。
- 基本信息第一项是所属环境。只有一个环境时只读展示，并在抽屉里新建环境，说明保存后不能更换。保存后下拉列出全部环境并选中新建的那个，已经填写的连接、密钥保留。多个环境时用下拉，选中「展示名 · 调用标识」。编辑时环境只读，并说明创建后不能更换。类型选择页同样标明目标会落在哪个环境。
- 侧栏「填写说明」只留一句该类型能做什么。密钥说明是编辑时留空表示不改。证书要和私钥一起填；不支持带口令的私钥。
- 错误留在本页：字段级错误 + `aria-invalid`；结果区在操作按钮上方，不在页顶重复。
- 密钥：密码框 + 已设置徽标；留空表示不改。
- 操作：取消是链接；测试连接是独立按钮；保存是唯一提交按钮。新建时保存先禁用，测试通过后启用。编辑时连接未改可以直接保存。
- Mongo 只显示当前认证方式的字段。TLS/证书只在启用 TLS 或 SSL/SASL_SSL 时显示。
- 运行上限的说明是「这些上限作用于之后的工具调用」。

### 5.5 系统配置 `/settings`

左侧子菜单是真实链接。未保存时离开分组或页面会确认。保存留在当前分组并显示页内提示。非 SQLite 配置库不显示备份份数输入，只说明该项不适用。恢复单项列出当前值 → 默认值；恢复全部列出每一项，并说明目标、密钥和只读边界不受影响。认证与会话分组包含 Session 有效期、登录失败次数上限与锁定时长、每人 Token 上限与有效期；启动配置区只读展示监听地址、配置库、公网地址（仅展示）、Cookie Secure、受信 Host、日志级别和密钥来源。保存只记录发生变化的配置项。并发与审计分组还包含全局并发上限、审计清理批量与时限；高级资源分组包含连接器空闲回收。

### 5.6 环境 `/environments`

导航「环境」。副标题只说明展示名可以改、调用标识创建后不能改。列：展示名、调用标识、目标数、状态、操作（查看目标 / 编辑 / 删除）。有目标时不提供删除，说明原因。删除空环境走确认弹窗。新建环境是右侧抽屉，字段是展示名、调用标识和启用。从环境列表保存后留在列表里，并提示环境已创建。从目标页保存后留在目标页，并选中新建的环境。直接打开 `/environments/new` 仍是整页表单，保存后进入该环境的目标列表。调用标识提示小写字母、数字和连字符，创建后不能改，排查时要传这个值。编辑仍是整页。编辑 `default` 时说明调用标识不能改，要分开环境请新建。调用标识创建后只读；展示名和启停可以改。

### 5.7 删除确认

列表页 dialog：所属环境、目标名、类型、端点、授权范围、最近测试。说明删除后连接和密钥都会去掉，不能恢复。不显示「不可撤销」。Token 删除同样不显示该徽标；只有最后一个 Token 时说明 MCP 会暂时不能访问。取消与确认删除。

### 5.8 审计 `/audit`

导航在左侧「记录」组。只读。管理员看到全部操作者，副标题：查看已经发生的操作。分析员只能看到自己的记录，打开页面时动作默认是工具调用；选「全部动作」也只包括工具调用、生成 Token、删除 Token 和修改密码。

时间用三枚胶囊：近 24 小时（默认）、近 7 天、近 30 天，点一下就换，并保留动作、环境、结果和对象名。动作、环境和结果下拉、对象名搜索放在同一行，点「筛选」一起生效。有非默认条件时提供「清除筛选」。

表：时间、操作者、动作、所在环境、对象、结果、摘要。最新在前，每页 50 条。动作用安静徽标。结果列：工具调用与测试连接显示「成功」（绿）或「失败」（红，悬停看错误原因），没有成败语义的动作显示破折号。环境同时显示展示名和调用标识；没有环境时用破折号。摘要在表格里最多两行，点「查看」打开弹层。工具调用拆成返回条数、耗时、结果、调用信息和参数。结果卡片里的错误码显示为「CODE（中文标签）」（英文界面用半角括号），失败时下面附一行脱敏、截断后的错误消息；列表摘要预览保留原始码。调用信息里有请求号时，用它去对进程日志。有 SQL 时，SQL 单独一块等宽显示，只在空格处换行，超出可滚动；`limit` 和其它参数一样按名字和值列出。其它参数用名字和值，空值不显示，很长的值单独占一行。参数在写入时放不下整段的，说明已经截短，并给出留下的开头。复制的是弹层里看到的参数。其它动作显示原文，复制原文。已经写入的旧记录保持原样。概览里的同一弹层用同一套参数显示。没有记录时仍留下筛选，并说明可以改时间再看。

### 5.9 错误页

400/404/500 统一：大号状态码、标题、人话说明、返回概览。管理员另有系统配置入口。分析员打开环境、系统配置或用户时看到「没有权限」，页面不包含连接信息和密钥；目标页对分析员是只读版本。登录页填写用户名和密码。分析员首次登录只能修改密码，成功后退出，用新密码再登录进入概览。

### 5.10 用户 `/users`

只有管理员能打开。页面是成员列表，页头有「创建成员」。点击后从右侧抽屉填写登录名；初始密码可手填，留空则生成。生成后登录名和初始密码留在同一个抽屉里，只显示一次。复制得到这两行，不进地址，刷新后不能再看，审计只记登录名和角色。分析员的「是否启用」是开关，点一下即切换；操作列只保留重置密码。管理员那一行不能切换。停用后不能登录，已有 Token 也不能调用。重置密码会使网页登录失效，并要求对方下次登录时修改密码；Token 保留到停用或本人删除。不删除账号，也不能停用自己。

## 6. 响应式与可访问性

- 断点：登录后的主区域随窗口变宽，短列按内容宽，阅读列占满剩余；表单、安装、确认页保持 1180 窄栏。≤1120 表格转卡片；≤1024 表单变单栏、侧栏两列；≤900 左侧菜单改为顶栏下的换行链接、统计两列；≤640 顶栏换行、表单/卡片单列、按钮拉通。
- 键盘：跳转链接、焦点可见、逻辑 Tab 顺序、无陷阱；删除与保存都通过表单可达。
- 语义：`header/nav/main`、每页一个 h1、`aria-current`、表格 `scope`、`aria-pressed`、`aria-live` 提示、`aria-invalid`。
- 对比度：正文/次级/语义色 ≥4.5:1，大字与图标 ≥3:1；`tests/test_ui_contrast.py` 自动校验两套 token。
- 动效：120–180ms ease-out；`prefers-reduced-motion` 下全部关闭。

## 7. 验收

- 浅/深两套、1440/1024/390 三宽度：无横向滚动、无文字截断、无重叠（用 DevTools 协议检查 `scrollWidth == innerWidth`）。
- 主题：默认跟随系统；手选后立即换色并保持；清除后回到系统；首屏由服务端渲染，无闪烁。
- 键盘走查全部页面；对比度自动测试通过；`pytest` 全绿；CSS < 44KB；除自托管渐进增强脚本外无外部请求。
